# Pop The Feed

A bubble wrap pop game that serves up fresh stories. Pop a bubble, read the summary, tap Read More to open the full story.

Stories come from Boing Boing, Dangerous Minds, Phys.org, Atlas Obscura, Colossal, Hyperallergic, Aquarium Drunkard, Post-Punk.com and Good News Network. They refresh automatically twice a day.

Play it here: https://rnpgv784r4-alt.github.io/pop-the-feed/
